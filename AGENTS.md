# Project instructions

## Keep Discover aligned with every web update

The user explicitly requires maintaining `discover.html` alongside the main
JamdDmaj website. For every web update, review `discover.html`, `discover.js`,
`discover.css` and `discover-tour.css` for relevant content, navigation, version,
visual and accessibility updates. Include appropriate improvements in the same
release, and verify both the main website and Discover before declaring publication.

Use the canonical public page `https://www.jamddmaj.com/discover.html`; old
`?version=` links must not be treated as a reason to leave its content outdated.
Keep descriptions accurate to shipped functionality. Distinguish available
features from account-specific authorization, test networks and pending work.
Never advertise unverified trading readiness or invent plans/prices.

If no Discover change is appropriate for an internal-only update, explicitly
record that it was reviewed and why no content change was needed. Do not make
meaningless edits just to change its timestamp. Preserve the JamdDmaj identity
and incrementally improve mobile layout, clarity and usability when relevant.
