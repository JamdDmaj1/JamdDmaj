# JamdDmaj AI v1.23.0

Telegram control and formatting update for hidden Pro Signals.

- Added scan-frequency control: 1, 2, 5, or 10 minutes.
- Added minimum-quality control: A only or A+B.
- Added repeat cooldown control: 5, 15, 30, or 75 minutes.
- Added a manual Send now button that bypasses cooldown for the owner device.
- Improved Telegram messages with clear sections, bold labels, compact prices, human-readable times, and relevant emojis.
- Prevented the first manual Send now action from producing duplicate messages.

Automatic scanning still runs only while Pro mode is active and the app is in the foreground.
