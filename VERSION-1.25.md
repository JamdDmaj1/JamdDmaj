# JamdDmaj AI v1.25.0

Server automation, verifiable Pro history, controlled memory, accounts, notifications, and signed updates.

- Added a private 24/7 Pro scanner endpoint and five-minute GitHub Actions scheduler.
- Rotates through more than 50 crypto markets while keeping BTC, ETH, SOL, and XRP in every cycle.
- Added ATR, EMA, SMA, RSI, MACD, momentum, volume, structure, and Bollinger-position checks.
- Stores open calls and verified TP/SL/expired/ambiguous results in Upstash.
- Sends new calls and outcome updates to the configured Telegram channel.
- Added an owner-only server dashboard with run, pause, refresh, and live statistics.
- Added user-approved memories with review and delete controls.
- Added configurable Google account linking to the encrypted JamdDmaj Sync profile.
- Added native Android daily Learn reminders without an external plugin.
- Added signed GitHub Releases and an in-app update checker.
- Expanded automatic free web lookup intents while preserving source URLs and timestamps.

Google and the 24/7 scanner require the environment variables described in `SERVER-SETUP.md`.
