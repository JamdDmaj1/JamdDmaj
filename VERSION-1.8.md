# JamdDmaj AI 1.8.0

## Cambios principales

- Learn cambia correctamente con el idioma de la interfaz.
- Traducciones ampliadas para español, inglés, francés, alemán, portugués, italiano, japonés, coreano, chino y árabe.
- Botón para escuchar la pronunciación de las tarjetas de idiomas.
- Respaldo completo de chats, proyectos, ajustes y progreso de Learn.
- Restauración de respaldos desde un archivo JSON.
- Nombre JamdDmaj AI visible permanentemente en la cabecera.
- Apartado de redes oficiales.
- Tutoriales actualizados con respaldo, idiomas, audio y redes.
- Versión Android `1.8.0` (`versionCode 18`).

## Actualizar sin perder información

1. No desinstales la aplicación actual.
2. Descarga el APK 1.8 desde GitHub Actions.
3. Abre el APK e instálalo encima de la versión existente.
4. Android conservará el historial y los ajustes.

El workflow conserva la misma clave de firma de pruebas mediante la caché de GitHub. Si Android rechazara la actualización por una firma antigua, conserva primero la versión actual y avisa antes de desinstalarla.

Después de instalar 1.8 podrás entrar a:

`Ajustes > Datos y respaldo > Exportar respaldo completo`

Guarda ese archivo antes de cambiar de teléfono o reinstalar.
