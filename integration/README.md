# Local Squads / category vesting integration

Run on Linux with Node 22, after building `onchain/target/deploy/jamddmaj_lock.so`:

```
npm ci --ignore-scripts
npm ci --ignore-scripts --prefix integration
node integration/squads-vesting.mjs
```

The script reads the deployed Squads v4 binary and global configuration using
Mainnet RPC, then loads copies into LiteSVM. Every key generated by the script
is ephemeral and only signs transactions submitted to that local VM. The RPC
code only calls `getAccountInfo`. No user keys, network transfers, token launches,
or funded network wallets are required. SOL is minted by the emulator.

Four vesting accounts have distinct Squads vault beneficiaries. Tests execute
actual Squads proposals and nested calls into the compiled Jamd program. They
check one-vote rejection, timelock rejection, pre-cliff rejection, first tranche,
full release and a second claim after full release. Clock advancement is an
emulator facility; this is not elapsed-time evidence from Devnet or Mainnet.

The expanded rehearsal also creates the Token-2022 mint with the application's
metadata instructions, seals metadata, revokes mint authority, rejects additional
issuance, and reconciles all five allocation balances. Unvested allocations stay
in the local Squad's category vaults; no market or customer payments are opened.
Setup spans multiple transactions and is not an atomic launch. Policy creation
uses the temporary setup signer; governance of policy initialization and program
upgrade authority is not demonstrated by successful multisig vesting claims.

Output includes both binary hashes. A hash records the binary used; it is not
an independent audit or a reproducible-build attestation. External RPC reads
can fail, and the Squads binary may change between runs. Do not mark the test
passed when RPC, build, or execution fails.

The isolated SDK dependencies currently have npm audit findings (including
bigint-buffer, stream-json and uuid transitive dependencies). Install scripts
are disabled. These packages are not part of the web build or production
dependency tree. Do not reuse this environment for custody or production.

These tests do not cover public distribution, identity eligibility, real LP
tokens, Mainnet deployment authorization, or legal review.
